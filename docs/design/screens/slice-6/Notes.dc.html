Changes to the design system

None. Every colour, type step, radius and shadow is a token from the approved system (DEC-039), and the shell, table, form, side panel, dialog and badge patterns are its own. The graph uses tokens too: nodes are neutral background 1 with stroke 1, the focus CI a 3 px brand stroke, the selected CI the focus ring, a group a stacked outline; edges are neutral foreground 3 (the selected CI’s, foreground 1). Dotted and dashed are line styles, so the graph never relies on colour alone. The type icons are stand-ins, as on slice 5’s boards.
