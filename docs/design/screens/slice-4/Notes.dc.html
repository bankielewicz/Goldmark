Fluent v9 components

  • Shell: NavDrawer (inline at 1100 px and wider, rail below), NavSectionHeader, NavItem with aria-current="page"; Avatar + Menu; ToggleButton for the theme.
  • Header: Breadcrumb, Title3 as h1, Toolbar with Button "Export CSV…" (secondary, ArrowExport icon).
  • Notice: MessageBar intent="info", not dismissible.
  • Filters: Field + Dropdown (Time range; Action with multiselect and OptionGroup headers; Outcome), Field + Combobox (Actor, Person affected), Field + Input (Source IP), Button appearance="subtle" (Clear filters).
  • Table: Table, TableHeader, TableHeaderCell (sortable, Time only), TableRow, TableCell; expander Button appearance="subtle" with ChevronRight / ChevronDown and aria-expanded.
  • Badges: Badge appearance="outline" for the actor type; appearance="tint" with icon for the outcome (success, danger, severe).
  • Details: a definition list (dl) in a TableRow spanning every column; Link; Button appearance="subtle".
  • Export: Dialog modalType="modal", DialogSurface, DialogTitle, DialogContent, DialogActions, Spinner size="tiny", Toast.
  • States: Skeleton, MessageBar intent="error" with Retry, the shared 403 state, Tooltip.

Changes to the design system

  • Expandable rows use Table, not DataGrid. The data table pattern's DataGrid has no expandable rows. The audit log needs no selection or column chooser, so the board uses Fluent's Table primitives with an expander button per row and a details row spanning the columns. Everything else on the pattern (header, borders, Compact density, Load more) is unchanged.
  • "Blocked" outcome uses the badge vocabulary's severe intent (dark orange), as Degraded does, with a lock icon and the word.
  • No new tokens, colours or components.

Changes to the handoff

  • IP address header: an info button with the Tooltip "The address that connected to Goldmark. Behind a reverse proxy, this is the proxy's address." (owner's addition, DEC-041 item 4, #31).
  • The Auditor board shows the Failed outcome filter with three sample rows; the Link code wrong row was added to the sample data so that filter has more than two.
  • The 1024 board drops the IP column, as asked; the address stays in the expanded details.

Notes for the build

  • Data: GET /api/v1/audit (filters, cursor, total), /audit/catalog (labels, groups, outcomes, retention period), /audit/people (Actor and Person-affected options), POST /audit/export.
  • The Action filter's groups and labels come from the catalog; a later slice's actions appear without a UI change.
  • Filters live in the page address (query string), so a filtered view can be bookmarked.
  • The retention notice shows the catalog's period; 0 means "kept indefinitely" (DEC-041).
  • Times are UTC; the Tooltip shows the viewer's local time.
  • "Show this person in Users & roles" only for an Admin, and only while the account exists.
  • Nothing on the page edits or deletes an entry; only the export writes one (audit.exported).
  • Sample data is fictional.
