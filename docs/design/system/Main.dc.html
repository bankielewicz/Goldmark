Goldmark design system · Foundations

Tokens · colour

Fluent UI v9 webLightTheme and webDarkTheme, built with createLightTheme(goldmarkBrand) / createDarkTheme(goldmarkBrand). The 16-shade brand ramp is the only brand input; neutrals and status colours are Fluent's own tokens. Every value on this board was read from the installed themes (@fluentui/react-components 9.74.9: createLightTheme / createDarkTheme with this ramp) and every ratio computed with the WCAG 2.x formula. Slice 3 adds a unit test that recomputes them from the themes in code and fails below 4.5:1 for text and 3:1 for UI parts.

MessageBar uses the colorStatus* tokens instead: neutral text on the status background (14:1 or more) and a status-coloured icon (colorStatusDangerForeground1, colorStatusWarningForeground3, colorStatusSuccessForeground1; 4.9:1 or more on their backgrounds). colorStatusDangerForeground1 on the plain dark page is only 4.2:1, so it is never used for text outside a MessageBar. Field validation text uses colorPaletteRedForeground1 (5.9:1 / 5.2:1 on the page).
