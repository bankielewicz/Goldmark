Accessibility annotations

Every function works by keyboard alone, in both themes. Screens get axe checks in the Playwright suite in light and dark (NFR-A11Y-3), added with the first screens in slice 3. Every ratio below was computed from the installed Fluent themes with this brand ramp.

Focus

Light: 2 px colorStrokeFocus2 (black) outside, 1 px Focus1 (white) inside. 21:1 on the page, 3.5:1 next to the gold fill.
Dark: white outside, black inside. 14.6:1 on the page, 6.8:1 next to the fill.
  • Fluent's focus indicator on every interactive element, keyboard only (no ring on mouse click); never restyled, never gold.
  • Inputs show focus with their 2 px colorCompoundBrandStroke underline (5.9:1 / 4.8:1).
  • Order follows reading order: skip link, top bar, nav, page header, content.
  • Focus moves into a Dialog or Drawer on open, is trapped there, and returns to its opener on close (useRestoreFocusTarget for drawers). No other traps.
  • After a step change (sign-in, setup) focus moves to the step's heading; after a failed submit, to the error MessageBar.

Not required and not met: the dark primary button's fill against the page (2.1:1); its label identifies it (WCAG 1.4.11). Dividers (Stroke1: 1.5 / 2.5) are decorative only. Disabled text (1.9 / 2.2) is exempt and always paired with an explanation.

Targets

⋯32 × 32
⋯24 × 24 (compact)

At least 24 × 24 CSS px everywhere (2.5.8), including compact density. Icon-only buttons have an accessible name and a tooltip with the same words. Nothing relies on hover alone.

Colour is never alone

Status: icon + word (Down, Degraded, Healthy, Not seen). Selection: checkbox state and the selected-row fill. Current nav item: bar + bold text + aria-current. Errors: icon + text + linked to the field. Charts and graphs always have a table view (NFR-A11Y-2).

Reduced motion

With prefers-reduced-motion: reduce, drawers, dialogs, toasts, menus and the skeleton shimmer appear and disappear without movement. The e2e suite will check this by emulating the setting.

Reflow at 400 % zoom

A 1280 px window at 400 % is 320 CSS px wide: the nav becomes the overlay drawer, the top bar keeps the menu, search and account buttons, forms are one column, and wide tables scroll inside their own region, never the page. Text spacing overrides (1.4.12) do not clip text.

Live regions

Polite: search results counted, "Loaded 50 more", import finished, saved, copied (Toaster politeness="polite"). Assertive only for blocking errors (role="alert" on the error MessageBar). Loading regions set aria-busy.

Structure

One h1 per page (the page title), then h2 sections. Landmarks: header, nav "Main", nav "Breadcrumb", main. Tables use real header cells with aria-sort on the sorted column. Forms use visible labels, never placeholder-only; required fields say so in the label.
