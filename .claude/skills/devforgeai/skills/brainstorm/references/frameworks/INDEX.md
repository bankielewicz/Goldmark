# Brainstorming frameworks

Choose one row. Use the framework the user named; otherwise the one whose *use when* fits the
topic best and whose *avoid when* does not apply; otherwise `diverge-converge`, the default.
Then read its file, which sits next to this index.

| framework | file | use when | avoid when |
|---|---|---|---|
| diverge-converge | [diverge-converge.md](diverge-converge.md) | A new product, feature or problem space where options are wide open; the default | The user already has a fixed shortlist and only wants it ranked |

## Required sections

Every framework file has these sections, in this order. A file that lacks one is malformed:
use `diverge-converge` instead and tell the user which file was the problem.

1. When to use / When not to use
2. Steps
3. Questions to ask
4. Mapping to the BRN
5. Evaluation method text
6. Example

To add a framework, add its file here and one row to the table above. `SKILL.md` does not change.
