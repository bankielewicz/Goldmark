# Goldmark CMDB

> **Status: under development. Not yet installable.**
> There is no release, no supported install path and no working feature yet.
> Do not deploy this repository.

Goldmark (a working codename) is a planned self-hosted configuration management
database (CMDB) for Windows- and VMware-heavy IT estates. The intended scope is:

- automatic, read-only collection from vCenter, Windows (CIM), Active Directory
  and SQL Server, reconciled into one CI per real-world thing;
- typed relationships with redundancy-aware impact analysis;
- point-in-time history of every CI and relationship;
- a versioned API and webhooks for downstream tools.

The product requirements are still a draft and are subject to change.
